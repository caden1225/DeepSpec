# 专利实施例：理想数据画像

> 用途：界定「好看且能撑住权利要求」的目标形态。数字为**达标画像**，须由真实实验逼近，不可虚构填入申请文件。  
> 对照现状见 `实施例数据-占位.md` 与 `experiments/results/tools_aware_compare.json`。

## 1. 叙事目标（一句话）

同任务准确率下，区段感知策略的整体 \(\tau\) / Speedup **明显高于**全局固定策略，且增益集中在 TOOL 结构化区段。

## 2. 理想总表（tools-aware，greedy 无损）

| 方法 | \(\tau\) | \(\tau_{\text{NL}}\) | \(\tau_{\text{TOOL}}\) | Speedup | 结构准确率 |
|------|--------:|---------------------:|-----------------------:|--------:|----------:|
| 自回归 | 1.0 | — | — | 1.0× | ≥95% |
| 全局固定 \(B\) | 1.8–2.5 | 1.3–1.6 | 2.0–2.8 | 1.4–1.8× | ≥95% |
| **区段 CAS** | **2.5–3.5** | 1.3–1.6 | **3.0–4.5** | **1.8–2.5×** | ≥95% |
| 区段 + Schema | **3.0–4.0+** | 同左 | 再高一档 | **2.0–3.0×** | ≥全局 |

## 3. 理想分区表（CAS）

| Region | 相对全局 | 理想 \(\tau\) 量级 |
|--------|----------|-------------------:|
| NL | 持平或略保守 | 1.3–1.6 |
| TOOL_SKELETON | 明显高于全局 | ≥3.0 |
| TOOL_ENUM | 最高 | ≥4.0 |
| TOOL_FREE | 介于骨架与 ENUM | ≥2.5 |

单调性：\(\tau_{\text{ENUM}} \ge \tau_{\text{SKELETON}} \ge \tau_{\text{FREE}} \ge \tau_{\text{NL}}\)（允许 FREE 与 SKELETON 接近，但 ENUM 与 NL 必须拉开）。

## 4. 相对现状的达标线

| 指标 | 现状（B=7，200 样本 / 60 step） | 专利友好达标线 |
|------|--------------------------------|----------------|
| 整体 CAS vs 全局 \(\tau\) | 持平 1.30 | CAS 高 **≥20%**（更好 ≥40%） |
| \(\tau_{\text{TOOL}} / \tau_{\text{NL}}\) | ≈1.3× | **≥2×** |
| 绝对 \(\tau\)（tools） | ~1.3 | **≥2.5** |
| Speedup | 未测 | **≥1.5×**（P50；P99 有下降即可写） |
| tool_call 解析 / 名匹配 | 96.7% / 83.3% | 解析 ≥95%；名匹配尽量 ≥90% |

## 5. 逼近路径（合法实验，非造数）

1. Draft `block_size` 提到 **16–24**，与 StrategyTable 中 TOOL 激进块长对齐。  
2. 领域数据与步数加码（千级样本、百级 step）。  
3. 在线 Schema / ENUM 掩码（冲从属权项）。  
4. 评测含 NL+TOOL 混合回合，避免「全程 TOOL + B 封顶 → CAS≈全局」。  
5. 并列报告准确率与 Speedup，写明无损验证。
