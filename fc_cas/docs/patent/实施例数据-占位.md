## tools-aware 在线对照（30 条，已完成）

协议要点（对齐 Cockpit-Tool-Call）：

- `tokenizer.apply_chat_template(..., tools=sample["tools"], enable_thinking=False)`
- Qwen3.5 XML：`<tool_call><function=…><parameter=…>`
- Qwen3.5 块验证因 hybrid attention 非无损；本实验采用**逐 token 目标模型验证**（greedy 等价）
- CAS：按 Region 调度 `block_size`（θ=0；草稿 B=7 为上限）
- Draft：`step_60`；`max_new_tokens=128`；temperature=0

### 条件总表

| 方法 | tools= | CAS | \(\tau\) | parse | name_match | 均 prompt tok |
|------|:------:|:---:|---------:|------:|-----------:|-------------:|
| 无 tools / 全局 | ✗ | ✗ | 1.021 | 0.00 | 0.00 | 16.4 |
| tools / 全局 | ✓ | ✗ | **1.302** | 0.967 | 0.833 | 973.1 |
| tools / 区段 | ✓ | ✓ | **1.302** | 0.967 | 0.833 | 973.1 |

注入 `tools=` 后 \(\tau\) 由 1.02→1.30（+27%），tool_call 解析率 96.7%。整体 \(\tau\) 与全局接近：本 draft `block_size=7` 已封顶 TOOL 区段，CAS 主要体现为**分区接受长度**差异。

### 区段策略下的分区 \(\tau\)（tools_cas）

| Region | proposals | \(\tau\) |
|--------|----------:|---------:|
| NL | 17 | 1.059 |
| TOOL_SKELETON | 628 | 1.272 |
| TOOL_FREE | 127 | 1.362 |
| TOOL_ENUM | 162 | **1.395** |

单调性：\(\tau_{\text{ENUM}} > \tau_{\text{FREE}} > \tau_{\text{SKELETON}} > \tau_{\text{NL}}\)，支持「内容感知 / 分区调度」主张。
