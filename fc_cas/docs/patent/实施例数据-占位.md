## 离线区段占比（test）

| Region | 字符占比 | 说明 |
|--------|----------|------|
| NL | 13.76% | 自然语言区段 |
| TOOL_SKELETON | 80.09% | 工具调用结构、固定键名和函数名 |
| TOOL_ENUM | 5.66% | Schema 枚举参数值 |
| TOOL_FREE | 0.49% | 工具调用中的自由参数值 |

test 集共计 991 条 assistant 序列（NL 173 条、TOOL 818 条），序列化字符总数为
109,625。TOOL_SKELETON 与 TOOL_ENUM 合计可由 template/enum 覆盖 94,004 个字符，
占全部 assistant 序列字符的 85.75%。

> 统计采用字符级近似：对每个序列化 assistant 前缀调用区段分类器，并将末位字符计入
> 该前缀所属 Region；该结果不等同于 tokenizer token 占比。
