# 内部备忘（不随专利递交）

## 保护组合取舍

| 选项 | 评价 | 结论 |
|------|------|------|
| 仅分区 block/阈值 | 有新意，但须与一般自适应阈值技术区分 | 作为独立权利要求主干，明确面向 FC 区段且 TOOL 更激进 |
| 仅 Schema 约束解码 | 约束解码已有较多公开 | 作为从属强化 |
| 区段调度 + Schema 槽位分化 | 与 FC 数据的结构化输出相符 | 作为保护组合 |
